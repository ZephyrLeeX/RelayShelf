# 保存搜索

保存搜索仅在 PostgreSQL 保存当前用户的视图名称和筛选条件，不保存消息结果、分页游标或正文。读取、更新与删除均按当前用户限制；管理员也不能读取其他用户视图。执行继续使用既有搜索接口及授权、敏感正文排除、生命周期和分页规则。

桌面侧边栏和移动端“我的”菜单可打开保存视图；搜索页支持另存、重命名、删除和明确的“更新当前视图条件”。搜索或修改筛选不会自动覆盖已保存条件。另存和更新使用表单当前条件；重命名保持保存的条件。

“最近 7 天”等相对时间每次打开重新按当前时间计算，表示滚动的 7 × 24 小时。自定义范围按消息创建时间筛选，精度为分钟，起点包含、终点不包含。可选中国标准时间（Asia/Shanghai，UTC+08:00）或 UTC。首版不增加高级语法，也不搜索敏感正文或附件内部。

标签删除、视图删除或条件不可用时停止查询并显示原因；修正后通过“更新当前视图条件”持久化。页面打开及重新获得焦点会重新获取保存视图，支持跨设备读取；不提供实时协作和修改冲突合并。

本次前端和测试依赖工作区已存在的 `000009_saved_searches.sql`、保存搜索 API/后端实现及生成类型。按用户指示，它们的既有未提交改动保留在工作区，不纳入本次新增文件和界面修改的提交。OpenAPI 空值枚举生成修复也保留在工作区，需与后端基础改动一起提交后，才能形成独立完整版本。
